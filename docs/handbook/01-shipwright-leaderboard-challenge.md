# ShipWright Leaderboard Challenge

> 
> **SHIPWRIGHT AI | CONTRIBUTOR CHALLENGE**

> Three leaderboard winners receive **₹500 Amazon vouchers each**.

> Track meaningful pull requests reviewed by ShipWright and merged by your team.

### How it works

ShipWright is the Technology Partner providing AI code reviews. It does not change or merge code for you.

> 
> **01. CREATE**

> Start one public GitHub repository per team.

> 
> **02. INSTALL**

> [Install ShipWright](https://github.com/apps/shipwright-agent) on the repository.

> 
> **03. OPEN PR**

> Create a feature branch and open a non-draft PR to main.

> 
> **04. REVIEW**

> Read its code review and suggested fixes.

> 
> **05. IMPROVE**

> Fix valid comments, push changes and merge.

> 
> **06. TRACK**

> [View the leaderboard](https://shipwright-agent.onrender.com/leaderboard).

### What qualifies as a meaningful contribution

- **Start date:** Qualifying PRs for this event must be opened on or after **13 October 2026**.
- **Repository:** Must be public and have the ShipWright GitHub App installed. One team member with admin permission can install it.
- **Pull request:** Must be created by a human in the team repository, reviewed by ShipWright and merged.
- **Size:** PRs with more than **5,000 changed lines** are skipped. Prefer focused changes.
- **Quality:** Actual, relevant code contributions count. Empty, bot-created, artificial or whitespace-only PRs do not count.
- **Review response:** PRs with fixes pushed after ShipWright's review rank ahead of PRs without subsequent fixes. Total counted PRs breaks the next tie.
> 
> **Review critically.** A ShipWright suggestion may be incorrect. Implement valid suggestions, explain inapplicable ones and do not merge unsafe changes.

### Troubleshooting and resources

<details open><summary>No review appeared after opening a PR</summary>

Confirm the GitHub App is installed on the repository, the PR is ready for review and the branch is in the team repository rather than a fork. You can comment `/shipwright rerun` on the PR to retry.

</details>

<details open><summary>How do the leaderboard and project submission connect?</summary>

Leaderboard contributions are tracked by ShipWright. Include the same public repository URL in your final hackathon project submission.

</details>
